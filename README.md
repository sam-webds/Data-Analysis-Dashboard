SuperStore Sales Dashboard
Project README | Microsoft Power BI
An interactive business intelligence dashboard designed to explore SuperStore sales performance and profitability across products, customers, shipping methods, payment modes, and geographic regions.
Project Overview
The SuperStore Sales Dashboard uses Microsoft Power BI to present sales information in a visual and easy-to-understand format. It helps users identify patterns in sales, compare product categories and customer segments, and explore regional performance to support data-driven decisions.
Key Features
•	Sales and profit analysis across product categories and sub-categories.
•	Customer-segment analysis to compare purchasing contributions.
•	Regional and state-level exploration of business performance.
•	Analysis by shipping method and payment mode.
•	Time-based exploration of sales trends.
•	Interactive visuals and filters for drilling into the data.
Tools and Technologies
•	Microsoft Power BI Desktop
•	Data visualization and business intelligence
•	Data cleaning and transformation using Power Query, where applicable
How to Open the Project
1.	Download or clone this repository to your computer.
2.	Locate the Power BI project file (.pbix).
3.	Open the file using Microsoft Power BI Desktop.
4.	Use the report pages, visuals, and available filters to explore the dashboard.
